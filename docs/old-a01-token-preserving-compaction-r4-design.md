# 旧A01の実読コード・テストを短縮するr4

目的は、未参照資料削減r3の判断情報と実行挙動を保持し、モデルが実際に読む2ファイルの入力量を減らすこと。対象はsrc/domain/universal_ingester.pyとtests/unit/test_universal_ingester.py。方法はPythonの字句解析を使う空白・字下げ・括弧内改行の短縮だけとする。式、識別子、文字列、コメント、関数順序、テスト項目を削除・分割しない。

## 維持する条件と変更範囲

元JSON TaskSpec、Free、全repository authority、現行仕様、他のファイル、CLI 0.159.0、Astra Low、共有Python3.14.5、依存、元oracle・Rating14、permission、時間境界と全担当トークン集計を維持する。個人指示と追加回答を含めず、新しい停止手順を加えない。

変更2ファイルについて、位置情報を除いたASTの完全一致と、空白・改行・字下げを除く全tokenの種別・内容・順序の完全一致を発行前に確認する。コメントと文字列も同一とする。元の関連39テストを両素材で実行し、収集項目・成否の一致を確認する。この検証は構文・既存テスト範囲の挙動についての証拠であり、モデルの判断経路の同等性はLow N2で観測する。

Git開始状態を隠すためのassume-unchangedやfilterは使わない。試験用素材だけに2ファイルの変更を含む派生commitを作り、元HEADを親として残す。派生HEAD・tree・stageの変更は素材短縮に伴う差として宣言する。detached、clean、既存refs、他のファイルは保持する。元HEAD完全一致を要求した画像・資料だけの投影とは区別し、元の試験や本体リポジトリを変更しない。新しい素材系列であり、プロンプト比較・旧素材のrun pool合算・Layer4登録を行わない。

## 確認試験

基準は未参照資料削減r3 Low N2。固定Layer1の同素材を複製し、変更2ファイルと派生Git識別子以外の一致、元実行器のhash、profile・TaskSpec・素材manifestのhashを事前照合する。証跡保存後だけ発行する。

Astra Low N2を実同時2、設定上限M24で実施する。無効や有効な低得点を自動再試行で置換しない。N20へ自動延長しない。停止、テスト先行、編集を分け、トークンと時間は実測として比較する。ファイル容量減をトークン減へ換算しない。
