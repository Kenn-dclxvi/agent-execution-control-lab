# 未参照資料削減r3の確認結果

[比較条件](old-a01-reduction-comparison-conditions.md)に沿い、資料削減r3のAstra Low N2を整理する。必要な判断入力と実行依存を保持し、未参照資料53件を追加除外した。2件とも有効で、確認停止1件、確認前のテスト1件、編集0件だった。今回の確認はN2で終了し、追加実行は行わない。

## 条件の照合

基準は[PNG除外r2のLow N20](../evaluations/results/control-free-astra-low-old-a01-exact-input-projection-r2-n20_2026-10-03.md)。変更対象はdocs/archiveとreportsの53件と、それを表すGit投影設定。元JSON TaskSpec、Free、全repository authority、対象コードとテスト、CLI 0.159.0、共有Python 3.14.5、依存環境、元oracle・Rating14、permissionと集計方法を保持した。

残る204ファイルのパス・種別・モード・内容を事前照合。HEAD、detached・clean状態、refsとstageのblobを保持した。実行後も、パスだけを正規化したCLI引数と基本指示・developer指示・環境・TaskSpecの一致、個人指示不在、追加ユーザー回答なしを確認した。設定上限はM24、実同時数は2。素材変更の別系列で、旧結果との同一プール合算やLayer4登録はしない。

一次結果のpreflight内のpreserved一覧には、継承された「M24 実同時実行1」という旧表記が残っている。今回の実同時数は、同じ記録のdeclared_differences、controller_preflight、actual_concurrencyにある2が実態である。この表記不整合を明記し、保存済み一次結果は書き換えない。

今回の合計は248,765トークン、各実行時間の合計は65.444秒。時間合計は並列試験全体の待ち時間ではない。試験全体の所要時間はこの集計から算出しない。

r2 N20の平均に対して今回の平均トークンは約7.0%少なかった。これは実測の差として記録する。反復数と動作構成が異なり、削減による効果として確定しない。基準と今回では並列の実行状況が異なり、r2には中断を含む実行もあるため、平均時間の差を資料削減の効果として扱わない。

## 容量と今回の判断

可視作業ファイルの論理容量は1,823,677から1,471,334バイトへ、352,343バイト（19.3%）減った。Git履歴のblobは保持しているため、物理ディスク使用量の削減は未計測。

今回確認できたのは、未参照資料を先に除外しても固定した判断入力・実行依存を保持して試験が成立し、旧素材で観測された停止とテスト先行の両経路が今回も現れたこと。トークン削減の因果、動作頻度の一致、Medium・Highを含む推論設定による動作差の保持は、このLow N2では確認対象を完了していない。

次の削減は実際に読まれるコードとテストを対象にし、判断情報と依存関係を維持する短縮方法を固定してから別版を作る。その確認もまず並列Low N2とする。
