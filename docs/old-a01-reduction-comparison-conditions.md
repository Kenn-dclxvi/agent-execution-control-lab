# 旧A01と削減版を比較する条件

目的は、旧A01の判断に必要な情報と動作差を保持しながら、測定のトークン、時間、作業領域容量を減らすこと。単に得点が似ていることだけで代替成立とはしない。比較の正本は[evaluationsの互換条件](../evaluations/AGENTS.md)、反復判断は[再現性の基準](reproducibility-decision-policy.md)とする。この文書は今回の削減系列への適用を整理する。

## 比較で動かすもの

| 比較の目的 | 変更する項目 | 固定する項目 |
| --- | --- | --- |
| 素材削減の影響 | 宣言したファイル除外、またはコード・文書の短縮 | プロンプト、モデル、推論設定、依頼、指示、採点、実行環境 |
| モデル・推論設定の動作差 | モデルまたは推論設定 | 同じ素材版と、それ以外の全条件 |
| プロンプトの効果 | プロンプトだけ | 素材を含む、それ以外の全条件 |

一度に複数の軸を変更しない。削減版は素材が異なる別系列であり、旧素材の実行と同じ互換プールへ合算しない。短縮で情報を変更する場合は、変更内容と維持する判断根拠を実行前に固定する。

## 固定する入力・環境

| 条件 | 今回の固定内容と照合方法 |
| --- | --- |
| 対象・ケース | the-captionの旧A01 r2。セット、ケース版、元oracle、Rating14を固定 |
| 依頼 | 元JSON TaskSpecをバイト単位で保持。追加説明、途中回答、停止を促す新指示、workspaceへの新TASK.mdを加えない |
| 指示 | Freeのプロンプトと元repository authorityを保持。全AGENTS.md、基本指示、developer指示を照合。個人のユーザー指示を含めない |
| 素材 | 同じ固定Layer 1から複製。保持ファイルのパス、種別、モード、内容、リンク先を照合。除外・短縮とGit投影設定の差だけを宣言 |
| Git開始状態 | 元HEAD b5c1cc6、detached、clean、refsとstageのblobを保持。通常の削除commitでHEADを変えない |
| モデル | 削減確認はGPT-6 Astra Low。固定モデル一覧を再利用。Medium・Highの結果をLowへ合算しない |
| CLI・実行器 | CLI 0.159.0の同一実行ファイルとhash、元execute関数、引数、permission、timeout、集計器を保持 |
| Python・依存 | 共有Python 3.14.5、固定依存、workspaceの.venv接続を保持。python不在や別のテスト方式への置換を混ぜない |
| 独立性 | 実行ごとに独立した作業領域と空の設定home。過去会話・メモリ・個人指示を混ぜない。認証は試験後に除去 |
| 並列 | 設定上限M24を保持。新しいLow確認は実同時2。実行順、実同時数、他の負荷、中断を記録 |

実行前に基準結果のIDとhashを固定し、変更予定以外の一致を照合した証跡を保存する。未確認または意図しない差があれば発行しない。実行後の指示配送照合は、事前照合の代わりではなく、実際に配送された内容の確認とする。

## 比較する結果

| 観点 | 記録・判断するもの |
| --- | --- |
| 動作 | 確認して停止、確認前にテスト、推測して編集、追加回答の有無。終了文だけでなく操作ログと最終差分で分類 |
| 得点 | 元採点を保持。0点のテスト先行と0点の編集を区別し、有効な低得点を除外・再試行で置換しない |
| トークン | cached inputを含む全担当の入力・出力・合計。同じ集計版で総量と1実行当たりを示す。資料のバイト削減をトークン削減へ換算しない |
| 時間 | CLI開始から返却までの各実行時間と、並列試験全体の所要時間を分ける。並列数や中断が異なる履歴との差を削減の効果へ帰属させない |
| 容量 | 可視作業ファイルの論理容量と、Git履歴・依存環境・複製方式を含む物理使用量を分ける。疎な投影だけでは履歴blobは消えない |

新しい削減版はまずLow N2を並列実施する。N20へ自動延長しない。有効な反例はN不足で未確認へ戻さない。追加が必要な場合は目的と上限を先に固定し、同じ素材・条件の有効な独立実行だけを再利用する。N5・20・50は全段階を必ず実施する義務ではない。

旧試験の推論設定による動作差まで代替するという判断には、同じ素材版でLow・Medium・Highを比較した証拠が必要。Low N2の完了だけをその達成とは扱わない。
