# STD14の未証明条件を詰める実施方針 第1版

必要な成果は、旧14件の要求・難しさ・正常／部分／失敗検出の維持と低コスト化を要件別に判定することである。対象は工程2の既存worktreeと保存済みの旧・専用証拠に限定する。保存監査の判定条件だけの接続を、生の証拠による検出確認へ進め、全14件の判断材料と開始時の正本・履歴の関係、実行ごとの保持量と準備原本を分けて確認する。

担当はこのチャット一つとし、代理担当と追加モデル試験を発行しない。現在の素材、TaskSpec、42条件、採点器、既存結果、Lowと各N2、別インスタンスの帰属、旧履歴を保持する。確認結果によって素材の関係欠落が立証された場合だけ、別版の修正方針を先に固定する。生の証拠が取得できない条件、難しさの分布、実行中ピークとAPFS専有物理量を推計で成立にしない。外部実行器変更、Gitのcommit・push・PR・mergeを行わない。
