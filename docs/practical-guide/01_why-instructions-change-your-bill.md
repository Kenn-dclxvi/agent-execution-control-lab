# AIへの指示を足したら、料金が下がった

> 実務ガイド 1 / 3

AIに仕事を頼むとき、指示は短いほど安い。そう思っていませんか。

実際に測ってみたら、逆でした。**指示を6行足したら、試した4つのAIすべてで、料金が1〜3割下がりました。** しかも、全件が満点になりました。

この記事では、なぜそうなるのかを説明します。

## 何を比べたのか

AIのコーディングエージェントに、同じ14個の課題を5回ずつやらせました。変えたのは、リポジトリのいちばん上に置く指示ファイル（`AGENTS.md`）だけです。

- **Free：** 指示ファイルが空
- **最新版：** 指示ファイルに6行だけ書いたもの

14課題1セットあたりの料金（中央値）は、次のとおりです。

| AI | Free → 最新版 | 差 |
| --- | --- | ---: |
| GPT-6.1 Sol Low | $0.93 → $0.64 | 約3割安い |
| GPT-6 Astra Low | $6.15 → $4.12 | 約3割安い |
| Claude Code Sonnet 5.5 low | $0.70 → $0.62 | 約1割安い |
| Claude Code Opus 5.5 low | $1.27 → $1.12 | 約1割安い |

品質も上がりました。Freeでは、どのAIでも満点にならない実行が1〜5件ありましたが、最新版は4つのAIとも70件すべてが満点です。

1,000セット回すと、Sol Lowでは約$290、Astra Lowでは約$2,000の差になります。

## AIは、作業中ずっと読み直している

指示を足したのに安くなる理由は、AIの料金の数え方にあります。

AIの料金は、読んだ文字の量（トークン）と、書いた文字の量で決まります。そしてコーディングエージェントは、ファイルを開いたりコマンドを実行したりするたびに、**それまでのやり取りをすべて読み直してから**、次の一手を考えます。

読み直す部分には割引があります。一度読んだ部分は「キャッシュ」として覚えておけるので、2回目以降は安く読めます。たとえばGPT-6.1 Solでは、キャッシュから読む料金は通常の20分の1です。

ただし、**新しく受け取ったもの、つまり開いたファイルの中身やコマンドの出力は、毎回通常の料金で読まれます。**

なので、料金を押し上げるのは次の2つです。

1. **一手の数。** 一手ごとに、やり取り全体を読み直すからです。
2. **新しく受け取る量。** 通常の料金で数えられるからです。

指示ファイルの6行は、最初に一度読まれるだけで、あとはキャッシュから安く読まれます。

## 6行で、何が減ったのか

Sol Lowで、14課題1セットあたりの中身を比べてみます。

| | Free | 最新版 |
| --- | ---: | ---: |
| 一手の数（ツールの呼び出し） | 80回 | 58回 |
| 受け取ったファイルの中身や出力 | 約526KB | 約287KB |

一手の数は約3割、受け取る量は4割以上減りました。指示ファイルは1.7KB増えましたが、作業中に受け取る量が約240KB減ったので、全体では安くなっています。

減った一手と受け取りは、たとえば次のようなものです。

- やることが決まっていないのに、推測で作業を始めて、やり直す
- 方針が決まった後も、念のための調査を続ける
- 作業が終わった後に、確認をもう一度やる
- コマンドの終了を、短い間隔で何度も見に行く
- テストの出力を、何百行もそのまま受け取る
- 長いファイルを、必要な部分だけでなく丸ごと読む

どれも、人が見れば「そこまでしなくていいのに」と思う動きです。AIは止める理由がないと、こうした動きを続けます。**その間も、料金は数えられ続けます。**

## 「依頼」と「制御」は別のもの

ここで、二つのことを分けて考えると分かりやすくなります。

- **依頼：** AIにやってほしい仕事（「この不具合を直して」）
- **制御：** その仕事を、いつ始め、どこまで調べ、どこで終えるか

依頼をいくら丁寧に書いても、制御が書かれていなければ、AIは始め方や終え方を毎回自分で考えます。その迷いが、一手の数と受け取る量になって、料金に出ます。

今回の6行は、依頼ではなく制御だけを書いたものです。だから、14個の課題のどれにも、同じ6行をそのまま使えました。

## これだけ覚えてください

**AIの料金を決めるのは、指示の長さではなく、作業中の一手の数と、受け取る量です。**

削るべきなのは指示の文字数ではありません。AIの無駄な一手と、受け取らなくていい出力です。

では、その6行に何をどう書けばいいのか。続きは[「料金を下げる指示の書き方」](02_how-to-write-instructions-that-cut-cost.md)で説明します。
