# Standard14の縮小検討：Free・C147・C276（2026-10-03、第1版）

## 結論

**日常の比較試験は14項目から10項目へ減らす案を推奨する。ただし、全体評価を同じ意味で置き換えられると確認した項目は0件である。** 保存済み結果では全14項目にコスト差があり、品質が常に同じという理由だけでは削除できない。既存Standard14、固定ケース、採点、履歴、プロンプトは変更せず、10項目案を検討記録として保存した。新しい評価枠は発行していない。

常時試験から外す候補はF01、F03、F05の単位・モード確認、F05の範囲外の本番配備の4項目。残す10項目はA01、A02、F02、F04、F06、F07の2項目、F08、F10の2項目。各N=5では70実行から50実行へ減り、実行件数は28.57%減る。トークン量や実時間が同率で減るという意味ではない。

## 対象と比較境界

GPT-5.6 Sol、GPT-6 Sol／Luna／Astra、GPT-6.1 Solについて、指定されたFree・C147・C276の不変バンドルとStandard14全件coverageを持つ結果を棚卸しした。公開側のresultディレクトリと非公開registryにある同一result IDの複製は一つにまとめた。34 resultを確認し、30件は各N=5、4件はC147の累積N=29／53／77／100である。行数の合計5,726には累積resultの重複runが含まれるため実行数とは呼ばない。run IDを重複除去した観測は3,430件。全34 resultの内容ハッシュとケースcoverageを検証した。

互換キーが同じ異なるプロンプト間だけで16組の比較を作った。モデル、推論設定、CLI、個人指示隔離、採点、fixture、時間記録条件が異なる結果を同じ比較へ混ぜていない。C147とC276が全モデル・推論設定で揃っているわけではない。GPT-5.6のC276はこの棚卸しでは確認されておらず、推測で比較を補わない。Claude Opus 5.5はGPT-5.6以降の主分析に含めない。今回のモデル群以外、別インスタンス、旧12項目、局所A01縮小版は対象外。

## 判定方法

1. いずれかの保存結果で4点未満があるケースは残す。得点中央値だけで個別失敗を隠さない。
2. 同じ互換キーの各比較について、反復ごとのケース合算トークン・時間の中央値を計算する。元の全14項目と縮小集合で、丸め前の増減方向が一致するかを確認する。
3. 品質失敗がある7ケースを固定し、残る7ケースの128部分集合を保存結果だけで調べる。成功動作のツール順や実行手順を転記せず、評価項目の情報量を確認する。
4. 項目別の差、全体の増減方向、差の大きさ、試験が扱う成果条件の範囲を区別する。方向一致を評価同等性へ昇格させない。

## 運用案と未確認の範囲

10項目は、日常のプロンプト比較で明らかな品質低下やコスト方向を早く判断するための対象試験として扱う。14項目の全体評価完了と呼ばず、採用・release判断を引き継がせない。省く4項目の固有成果や許可境界を変える差分では、対応する項目を省かない。全体評価が必要な判断ではStandard14を維持する。

この集合は保存済みデータを使って選んだため、同じデータでの方向保持は事後的な当てはまりである。未評価のモデルや候補での同等性、低頻度失敗の不在、項目の重複性を証明しない。一方、未観測の可能性だけを理由に追加反復は発行しない。この分析から試験条件を変える場合は新しい評価系列として明示し、旧14項目との差をプロンプト効果として比較しない。現行のセット、profile、ratingと履歴は上書きしない。

## 証拠と再現方法

[機械可読の分析記録](standard14-free-c147-c276-case-reduction-assessment-r1.json)に34 resultの所在・ハッシュ、低得点の条件別内訳、16比較のresult ID対応、ケース別差率、単独除外による反転、最小集合、10項目の再集計値を保存した。各結果の`case_results`から同じケースと反復だけを抽出し、反復別合算の中央値を計算すれば表を再現できる。非公開registryのresultは参照可能性の境界を記録し、生の実行ログや認証情報は含めていない。

GPT-5.6の追加証拠として、[Free対C147のN=100比較](../evaluations/results/control-free-candidate147-v14-medium-standard14-atomic-n100-cli0146_2026-08-03.md)は全14ケースでC147のトークン・時間中央値がFreeを下回っている。上記16組の再集計は同じ全件result形式を持つN=5結果に限り、N=100の文書表を擬似runへ変換して混ぜていない。累積C147結果も独立反復として加算していない。
