# C280・C282のF08分割経路の独立した追加確認

2026-10-07、追加発行前に固定。目的、原文、対象系列は[先の計画](c280-c282-randomized-route-comparison-plan-r1.md)と同じ。F04の新規比較では長い経路0 / 15対1 / 15で、以前の3 / 5の増加を再現しなかった。F08は以前の1 / 5対3 / 5に続き、新規でも1 / 15対3 / 15の正方向の差を観測した。この繰り返した条件差と、短い経路の分布の差を確認することを追加理由とする。単に未確定だから追加するものではない。

F08だけを各条件で累積20件から50件へ、不足30件ずつ追加する。新規60件。F04と他ケースは追加しない。既存結果・採点・プロンプト・実行条件は維持し、同時期の共通待ち行列で組の順序と組内の先行条件を新たに無作為化する。実行担当はroot。観測、採点、登録、保存を完了し、N=50で終了する。

主診断は前のまま、root外側ツール呼び出し8回以上。補助診断は全分布、変更後確認の返却境界、全エージェントトークン、経過時間。閾値や採点を変更しない。過去5件と同時期の無作為化15件、新しい30件を別々に保持する。追加30件の独立した確認を主結果とし、同時期比較を合算した45件と累積50件も別に示す。

追加30組では正確McNemar検定を使う。先のF04、先のF08、今回F08の3判定を一つの集合としてHolm法で調整し、調整後p値0.05未満かつ正の差なら追加文による増加を支持する。逆方向なら減少を支持する。非有意の場合、増加の原因を追加文へ確定せず、観測したばらつきと残る効果の上限を報告する。同時期45組合算の検定は補助診断とし、主判定の不成立を反転させる根拠にしない。

条件と事前照合、外部失敗の再試行、採点・atomic登録・保存・最終圧縮は前の計画と同じ。全14ケースN=50試験として登録しない。N=50後に未確定を理由に追加せず、採用・release・本体反映は行わない。
