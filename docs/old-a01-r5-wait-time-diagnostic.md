# 分離版r5の時間増加の切り分け

前の比較報告で未確定とした時間増加について、保存されたr5のログを調べた。テスト先行のlow-02は確認質問を発行した後にsleepを60秒実行しており、返却値は60.0056秒だった。CLI全体111.610秒のうち、この待機が約60秒を占める。通常のコマンドを包むtoolの記録は4件で合計約1.5秒であり、テストの実行自体が60秒かかったものではない。

残りの約51.6秒はCLI起動、モデル応答、tool処理などを含む。モデルの推論時間だけとは呼ばない。待機を差し引いて比較KPIを置換せず、元の111.610秒と平均70.910秒を保持する。新しい試験にも待機禁止を追加しない。同じ実行条件・時間境界の下で、確認後の待機も行動の違いとして記録する。

この記録は時間増加の原因を補うものであり、r5のトークン減少、得点、実行時間の一次記録を変更しない。[抽出証拠](old-a01-r5-wait-time-diagnostic.json)、[元比較報告](old-a01-read-input-reduction-r4-r5-report.md)を参照する。
