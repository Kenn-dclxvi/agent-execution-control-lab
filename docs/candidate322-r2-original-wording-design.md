# Candidate322 r2 原文に戻す範囲

C321を本文の正本、直接の複製元、評価時の比較元とする。[初版の設計](candidate322-c321-reduction-design.md)を点検したところ、根拠の例示を縮めた文は依頼が指定する消去法まで禁じるように読めた。出力取得の二項をまとめた文は、全文を受け取ってから一部だけ読むことを許すように読めた。この二か所にはC321の原文を使う。

削るのは、第1項末尾の「対象の場所や具体的な実施方法が未確認なだけなら、利用可能な情報や環境を確認し、自分で決めて進める。」だけとする。第1項が停止を求めるのは結果が未確定の間であり、第2項は対象と実施方法を決める調査を認める。新たな操作や確認手順は加えない。ルート以外の18対象もC321から引き継ぐ。

FreeはA02で270件とも自力で進んだ一方、A01では未確定の結果を確認する前に操作した例がある。評価時は初版設計と同じ固定条件でC321と比較し、A01での先走りとA02での不要な停止を区別する。修復・周辺への影響・検証は別に照合する。条件が一致しない場合は比較を止め、品質が下がった場合は維持できたと判定しない。[再採点記録](../evaluations/results/a02-r2-behavioral-rescore-v1.md)
