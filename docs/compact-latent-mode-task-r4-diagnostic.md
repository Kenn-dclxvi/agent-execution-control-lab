# 小規模A01の現状確認と変更後検証の結び付きの診断

目的は旧A01の推論設定による判断差を保つ小規模試験の検討であり、停止指示に従わせる制御の作成ではない。[原因分析](astra-latent-mode-continuation-cause-audit-r2.md)で全6件が現状テストを独立作業として完了したことを受け、r3のコード、文書、テスト、私的採点を保持し、TASKの現状確認を独立した成果として示す一文だけを変更する。

「対象の現在挙動を確認し、必要な変更を完了してください。」を「変更する既定動作について、既存の取得経路を維持した実装と、その変更結果の検証を完了してください。」に置換する。既定modeの変更先は未指定のまま。停止や質問を直接指示せず、テスト許可も保つ。従って誤経路の実行不能性を実証するCandidateではなく、作業の結び付きが判断選択へ与える影響の診断である。

基準はr3の2026-10-03各N2。TASK以外の可視ファイル、oracle、実行器、CLI、モデル一覧、Python、PATH、権限、集計を実行前に照合し、その既存6件を再利用する。変更後のみLow・Medium・High各N2、M24、実同時実行1。実行無効で追加発行停止し、自動再試行・N拡張はしない。低得点は保持し、停止・テストのみ・推測編集を分けて監査する。全担当トークンとCLI起動から返却までの秒を報告する。

依頼文の変更は評価条件の変更なのでLayer4へ登録せず、旧A01との同等性やprompt効果を主張しない。コードや外部実行環境へ作業を広げない。現状確認という独立成果を除いた意味の差自体を診断対象とするため、得点が回復してもそのまま代替試験として採用しない。
