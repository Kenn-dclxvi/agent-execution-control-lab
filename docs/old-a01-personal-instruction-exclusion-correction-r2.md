# 旧A01の環境差監査に対する訂正

2026年10月3日の利用者訂正に基づき、直前の[環境差監査](old-a01-original-environment-transfer-audit-r1.md)の判断と復元方針を訂正する。最新のN試験では個人のユーザー指示を測定へ混入させないことが必要条件である。[N20計画](astra-a01-old-compact-n20-plan-r1.md)も小規模版について個人指示除外を固定条件として明記していた。

今回の4件で個人指示を除外したことは正しい。この指示の不在を移植不備と判定し、旧追加15件の個人指示を固定入力へ戻すべきとした前版の提案は撤回する。リポジトリ内へコピーしても個人指示の混入であることは変わらない。

反対に、旧追加Low15件に個人指示が配送されていたという監査の観測は、最新の除外条件を満たしていない旧結果側の問題を示す。旧N20の全件停止は当時の実効入力の実績として保持するが、個人指示を除外した統一条件のN20実績とは扱わない。旧の既存5件は当該指示の配送なしで全件停止していたため、指示の混入だけが旧新差の原因とは断定しない。

今回の4件の結果を個人指示の不在という理由で無効にしない。ただし、CLI、提示能力、スキル等の環境差が残るため、旧結果との比較で画像削減の単独因果を確定できるわけではない。以後の比較は個人指示を除外した条件を維持し、旧環境側も同じ除外条件にそろえることを前提とする。本訂正では追加試験、過去の得点変更、個人指示の復元を行っていない。
