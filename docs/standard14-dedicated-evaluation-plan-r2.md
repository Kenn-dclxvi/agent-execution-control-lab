# STD14専用評価の全体計画見直し 第2版

2026年10月4日。利用者の「同じことを繰り返しているから、計画から見直して」という依頼に基づく。今後の進め方は本文書を正とし、第1版と各工程の固定記録は当時の成果として残す。

**工程8の履歴復元を、そのまま次の実装へ進める計画を取り下げる。現在の試験系列は代替不認定で区切り、追加測定禁止のままでは認定まで到達しない修正を積み重ねない。** 全14ケースの要求・維持条件・判断材料・難しさを保つ低コストな評価代替という目的は変えない。目的を達成した、または断念したという判定ではない。

## 今回の成果・対象・方法・維持条件

必要な成果は、繰り返しの原因を除き、目的まで到達できる条件と、現在の権限で到達できる範囲を分けた全体計画である。対象は既存の工程2作業領域にある第1版計画、工程3〜7の確定結果、未実装の工程8方針に限定する。担当はこのAstra Highチャット一つ。保存済みの判定から成果と残件を一度整理し、元の目的へ接続しない次工程を取り除く。既存の局所照合やモデル試験は再実行しない。

元TaskSpec、全14件・42条件、採点、素材、旧新の結果、各N2、Low不再発行、旧履歴、別インスタンス帰属、通常checkout、無関係の変更を維持する。追加モデル実行、素材の実装、新worktree、別チャット、代理担当、外部executor・CLI・hook変更、commit・push・PR・mergeは行わない。[改訂記録](../evaluations/targets/standard14-dedicated-control/registrations/evaluation-replan-r2.json)に入力と実際の作業設定を結ぶ。

## 規則の適用範囲も分け直す

[規則の影響調査](standard14-dedicated-rule-impact-audit-r1.md)で、プロンプト比較用の完全一致条件と、今回の素材対応の区別が曖昧になっていたことを確認した。素材が異なるだけで不成立とせず、旧新を同じプールへ混ぜずに、宣言した素材差と保持必須の意味・環境を分けて判定する。新系列内のプロンプト比較では、従来どおりprompt以外を固定する。過去の発行前記録を追認しない規則は維持する。

古い局所AGENTSの「今回0件」は工程2の文脈を持つ。現在の追加測定禁止は引き継ぎ依頼にもあるため維持するが、保存証拠の調査と比較設計の禁止には広げない。作業モデル切替は利用者指定を保持し、小さな確認ごとの切替は追加しない。規則本文は今回変更しない。

## なぜ繰り返しになったか

| 計画上の問題 | 保存記録で起きたこと | 今回変えること |
|---|---|---|
| 局所受入と最終認定の間の出口が具体化されていなかった | 工程3の42条件対応を受け入れて測定した後も、「難しさが未証明」が残り、何を追加すれば終わるか定まらなかった | 契約対応、測定成立、難しさ、費用を分け、各判断の証拠と到達限界を先に固定する |
| 比較条件を一括で確定せず測定へ進んだ | 旧Lowの構築情報差を直した第2版でも、容量2項目の差が残った。後から履歴とbranch差も見つかった | 次の実測が許可される場合は、全14件の開始状態・配送・環境を一つの固定版として受け入れてから発行する。形式修正だけの再測定はしない |
| 異なる種類の証拠を、目的達成へ近づく同じ一歩として扱った | 失敗72件の検出、保存量、開始記録の照合が順に完成したが、いずれも新素材での難しさを実測した証拠ではなかった | 確認済み項目は閉じる。別の不足を埋める代わりに再確認しない |
| 観測された差から修正仕様を広げすぎた | 工程7から工程8では、旧rootの5980 byte、空コミット、branchを戻す案を、次の必須実装として置いた | 観測差と修正方法を分ける。root削除が判断に使われた証拠は保持するが、全文復元が唯一の必要十分な解決だとは扱わない |
| 許可された作業と、認定に必要な作業がつながっていなかった | 新しい素材を作る計画なのに、追加モデル試験は禁止され、既存Lowも再発行できない | 新版の実装前に、認定に必要な証拠を取得できるか確認する。取得不能のまま実装と最終確認を往復しない |

これは証拠確認そのものが不要だったという意味ではない。計画の欠陥は、確認のたびに別の次工程を足し、全体の終了条件と権限の整合を取り直さなかったことである。

## 現在の系列で確定すること

| 要件 | 現在の判定 | 証拠の役割 | 今後の扱い |
|---|---|---|---|
| 全14件の要求・42条件・コードと採点の対応 | 工程3の範囲で受入済み | 要求と実装・判定の構造対応 | 関連成果が変わらない限り再審査しない |
| 保存失敗72件を誤って満点にしないこと | 確認済み | 保存差分・応答・操作を使う検出感度 | 新素材で同じ失敗が起きる確率の証明にしない |
| 専用Low・Medium・High各N2 | 各28件、合計84件を保存済み | 当時の専用素材に対する実測 | 新版の実測へ転用せず、そのまま保持 |
| 旧第2版の各設定N2 | 合計84件を保存済み | 当時の旧素材に対する実測 | 専用側と同じ実行プールへ統合しない |
| 旧新の完全な条件対応 | 不成立 | 未宣言の開始記録・履歴・branch差がある | 記録の後補い、再ラベル、後付け説明で成立させない |
| モデルにとっての難しさの対応 | 未証明 | 高得点、同じ失敗の検出、同じN2の比率だけでは足りない | 現結果から同等と認定しない。逆に全ケースが易化したとも断定しない |
| 費用と保存量 | 差の観測は保存済み、同等代替の費用認定は不可 | トークン・時間・配送量、終了後の論理保持量 | 約70%の終了保持量差を総容量・ピーク・物理量の削減へ広げない |

これで、現在の系列の採用判断は「低コストな同等代替としては不認定」と確定する。未観測の可能性を理由に同じ系列の監査、報告、局所修正を追加し続けない。個々の有効なモデル結果や低得点を無効にする判定ではない。

[工程7の観測・判定](standard14-dedicated-stage7-final-verdict-r1.md)は保存する。ただし、そこから定めた[契約第2版](../evaluations/targets/standard14-dedicated-control/registrations/stage7-start-state-contract-r2.json)と[工程8方針](standard14-dedicated-stage8-material-revision-plan-r1.md)は、未実装の修正案として保持し、現行の実装指示から外す。履歴に差があるという事実は撤回しないが、旧root全文の復元を次の確定作業にはしない。

## 比較設計で先に決め切る内容

次の設計が実施可能になった場合も、今回までの個別修正案を順に実装しない。全14件を一つの比較契約へ結ぶ。

**保持する課題の関係。** 元TaskSpecの要求、未指定の利用者結果、正本から決まる方法、依存、許可境界、検証、報告、正常・部分・失敗の区別を42条件へ結ぶ。開始treeの正しさと、モデルが開始状態を判別するための材料は分ける。月次の固定seed差分など、課題が直接要求する履歴は必須とする。root削除のように開始判断へ影響した材料は除外を既定とせず、その役割を旧新でどう保持するか先に決める。必要なのは判断関係の保持であり、すべての旧Git objectの完全複製ではない。

**比較する環境。** 全14件について実際の開始記録、HEAD・branch・親・参照、path/type/mode/content/symlink、実配送、正本、実行器、依存環境を同じ時点で結ぶ。11項目が同じだけでは通さない。実行前ゲートはモデルへ成功ラベルを渡す方法ではなく、評価側の実物照合にする。開始後の状態を開始前証明に使わない。

**難しさの判断範囲。** 正常成果・部分成果・誤停止・禁止操作・不要実行・無根拠の指摘を、各ケースの元要求へ結んで観測する。平均点や同じ失敗率を合格条件にしない。N2の観測はそのケース・モデル・設定・入力に限定し、母集団としての難易度分布の同等性を証明したとは呼ばない。判断材料の保持に具体的な反例があれば不成立、対応を判断できる証拠が足りなければ証拠不足とする。少数の一致だけを理由に同等とはしない。どの観測を使って「対応する」と決めるかが実行前に定まらない設計は、測定へ進めない。

**費用の判断。** 品質と上記対応が成立した範囲に限り、設定別の同じ14件・各N2の全担当トークンと同じ時間境界の経過時間が、ともに減った場合だけ費用改善の方向を認める。個別ケースの退行、反復差、動作分類別の値を残し、停止構成の違いによる平均差を素材短縮の効果としない。実配送量とストレージは範囲別の観測として併記する。片方だけの改善、または対応不成立なら「低コストな同等代替」と認定しない。

これらは将来の実行前に完成させる設計の要件であり、この文書で比較準備が完了したと宣言するものではない。未確定の合否条件を実装担当へ投げて素材修正を始めることを防ぐために、入口をここへ戻す。

## 現在の制約と到達可能な結論

既存の専用84件は現行素材の結果であり、履歴や開始状態を変えた新版の結果として使えない。旧側の記録を修復しても、過去の発行前証明を新たに成立させることはできない。したがって、**追加モデル試験禁止・Low不再発行を維持したまま、新版のLow・Medium・High各N2の実証へ到達する計画は成立しない。** MediumやHighだけに縮めても、元の全設定の目的は満たせない。

この不整合を、もう一つの局所検証や報告書で解消しようとしない。現在の許可範囲では、既存成果を保持し、現行系列の不認定と、工程8を直ちに実装しない判断を確定するところまでである。目的全体は未達として残す。追加作業の入口になるのは、素材実装・実測については必要な証拠を取得できる権限または条件の実際の変更であり、未証明事項が残っているという事実そのものではない。設計と調査は、対応する未完了要件を直接進められる場合に現在の許可範囲で行える。
