# 旧A01の未参照資料削減r3とLow N2確認

必要な成果は、元の判断条件を維持したまま未参照資料を先に削減すること。対象はPNGだけを除外した投影r2の過去資料とし、保持ファイルの内容を変えずGitの疎なチェックアウトで除外する。元JSON TaskSpec、指示、コード、テスト、設定、依存環境、CLIと採点を維持する。新しい削減の確認はまずAstra Low N2を並列で実施し、N20へ自動延長しない。

## 除外の根拠と維持条件

投影r2の20件のコマンドとモデルへ渡された出力、保持するコード・テスト・指示・現行仕様の参照を照合し、docs/archiveとreportsの53件を追加除外した。参照のあった両領域のREADMEは保持した。対象の判断経路についての調査であり、リポジトリ全体からの参照が皆無という主張ではない。

残る204ファイルのパス、種別、モード、内容を元と照合した。GitのHEAD、detached状態、開始時のclean状態、refsとstageのblobを保持した。疎なチェックアウトの設定と除外フラグは変更点として記録する。評価素材を変える別系列であり、プロンプトだけの効果比較ではない。

論理容量は1,823,677から1,471,334バイトへ減った。追加削減量は352,343バイト。Git履歴のblobを残すため、物理ディスク削減量として扱わない。

## 確認結果と次の対象

[Low N2結果](../evaluations/results/control-free-astra-low-old-a01-unread-artifact-projection-r3-n2_2026-10-03.md)は確認停止4点1件、テスト先行0点1件、編集なし。2件とも有効。合計248,765トークン、平均32.722秒。指示配送の一致と個人指示の不在を照合した。未参照資料の整理によるトークン削減を証明したとは扱わない。

次は繰り返し読まれたsrc/domain/universal_ingester.py（25,418バイト）とtests/unit/test_universal_ingester.py（21,843バイト）の短縮を検討する。挙動、判断情報、依存関係を維持する方法を先に固定し、別の版として作る。短縮はまだ実施していない。
