# 累積削減版r6：テスト準備処理の共通化

目的は、画像除外・未参照資料53件の除外・処理分離を保持したr5へ、テスト準備処理の短縮だけを加えて測定コストを減らすこと。失敗した空白短縮r4は含めない。比較の基準はr5 Low N2とし、旧素材やr3へ戻して作り直さない。

対象はtests/unit/_universal_ingester_cases.pyの一ファイル。繰り返されるファイルパス作成、UTF-8書込み、同じ3引数からのUniversalIngester生成だけを共通関数へ置換する。個々のCSV・JSON・日付・数値・期待値・assert・テスト名・テスト数を変更しない。共通関数を機械展開したASTが元ファイルのASTへ完全一致することを実行前に確認する。コメントを削除せず、短縮は該当する準備処理の範囲に限定する。

r5固定素材から複製し、変更一ファイルと対応する派生HEAD・tree・stage以外の205ファイル、除外55件、元TaskSpec、Free、全指示と仕様、対象コード・モード分岐、CLI0.159.0、Astra Low、共有Python・依存、元oracle・Rating14、permission、全担当トークン集計と時間境界を保持する。detached・clean、元r5 HEADを親として保持し、既存refsも維持する。素材変更の別系列として旧run poolへ合算せず、Layer4へ登録しない。

元の関連39テストについて収集IDと成否を両版で確認し、事前照合証跡を保存した後だけモデルを発行する。並列Low N2、設定M24・実同時2、再試行なし、個人指示と追加回答なし。N20へ自動延長しない。有効な低得点を保持する。動作、全担当トークン、CLI時間、論理容量を分けて記録する。

前回r5のテスト先行実行の111.610秒には、確認質問後のsleep60秒が含まれた。保存ログでsleepの実時間60.0056秒を確認した。これを新しい試験から除外したり、前回KPIから差し引いたりせず、同じ時間境界で計測し、原因診断として区別する。
